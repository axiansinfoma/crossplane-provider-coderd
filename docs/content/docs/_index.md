`provider-coderd` exposes the resources of the
[coderd Terraform provider](https://github.com/coder/terraform-provider-coderd)
as Crossplane managed resources.

- [Getting started](getting-started) — install the provider and create your first resource.
- [ProviderConfig](providerconfig) — credentials, and the difference between the cluster-scoped and namespaced flavours.
- [Managed resources](resources) — the kinds this provider serves.
- [Developing](developing) — how the provider is generated, and how to add a resource.

It requires **Crossplane v2**.
